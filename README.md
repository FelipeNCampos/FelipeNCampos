## Fontes e metodologia

<details>
<summary><strong>Como ler o painel</strong></summary>

- **Contribuições e dias ativos:** soma das contagens diárias do calendário visível sem login, no intervalo indicado no painel. Inclui atividade privada anonimizada quando o perfil permite sua exibição; não consulta código nem detalhes privados. O total pode diferir do cabeçalho do GitHub por cache ou diferenças na janela de consulta.
- **Calendário isométrico:** cada bloco representa um dia. A cor segue a intensidade informada pelo GitHub; a altura usa a raiz quadrada da contagem para manter os picos legíveis.
- **Horários:** eventos `PushEvent` em uma amostra de até 300 eventos públicos recentes, convertidos para o horário de São Paulo (UTC−3). Um push pode conter vários commits; o gráfico não mede horas trabalhadas. A janela efetivamente encontrada aparece no painel.
- **Dias da semana:** contribuições do calendário, agrupadas pela data informada pelo GitHub. É uma fonte e um intervalo diferentes da amostra de eventos por hora.
- **Linguagens:** soma dos bytes reportados pela API em todos os repositórios públicos próprios, incluindo arquivados e excluindo forks. As cinco maiores aparecem separadas; as demais são agrupadas em “Outras”. Bibliotecas ou arquivos de terceiros contabilizados pelo GitHub podem influenciar a distribuição. Não mede domínio, tempo de uso ou autoria de cada linha.
- **Repositórios, estrelas e forks:** o total de repositórios inclui os forks públicos do perfil. Estrelas e forks recebidos consideram apenas os repositórios próprios que não são forks.
- **Tecnologias:** seleção editorial baseada nos projetos e no README anterior; não é inferida como proficiência a partir de porcentagens.
- **Atualização:** o workflow é programado a cada seis horas e permite execução manual. Depende da disponibilidade do GitHub Actions e das permissões do repositório. O painel mantém a data da última coleta concluída; falhas na coleta não são substituídas por dados fictícios.

Os dados usados estão em [data.json](assets/metrics/data.json), com o horário da coleta. Consulte o [gerador](scripts/generate_metrics.py), o [workflow](.github/workflows/metrics.yml) e o [guia de manutenção](docs/metrics.md).

**Fontes:** [perfil público](https://github.com/FelipeNCampos), [calendário visível](https://github.com/users/FelipeNCampos/contributions), [repositórios](https://api.github.com/users/FelipeNCampos/repos?per_page=100&type=owner), [eventos públicos](https://api.github.com/users/FelipeNCampos/events/public) e [definição de linguagens em bytes](https://docs.github.com/en/rest/repos/repos#list-repository-languages).

A organização do painel foi inspirada no [README de Fabr1n](https://github.com/Fabr1n/Fabr1n). O gerador e os gráficos foram implementados para este perfil, sem reutilizar formação, vínculos acadêmicos ou realizações de outra pessoa.

</details>
